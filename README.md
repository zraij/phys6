# فيزياء السادس العلمي

شرح تفاعلي لفصول كتاب الفيزياء للصف السادس العلمي التسعة.

- **الموقع:** https://zraij.github.io/phys6/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/phys6/admin.html — لوحة الإدارة الموحّدة لكل الكتب (نفس `admin.html` بكل المستودعات): الحسابات، الاشتراكات، الأجهزة والجلسات

محتوى الصفحة مشفّر، ولا يُفتح إلا بحساب صحيح. الحسابات محفوظة في `users.json` بشكل مشفّر، وتُدار من صفحة الإدارة.

- **رابط التثبيت (يُرسل للأساتذة):** https://zraij.github.io/phys6/install.html — يثبّت البرنامج كتطبيق على الموبايل والشاشات التفاعلية
- **حساب الشاشة التفاعلية:** من صفحة الإدارة ← «إضافة شاشة تفاعلية»، حساب لكل شاشة حتى ما تنقفل حسابات الأساتذة عليها
- **تنبيه للمطوّر:** بعد أي إعادة بناء لـ `index.html` تأكد أن سطر `manifest.webmanifest` وكود `__PWA` بعده موجودان، وإلا يختفي التثبيت كتطبيق

## السبورة
زر «🖍️ السبورة» داخل الكتاب يقسم الشاشة نصين: نصف الكتاب ونصف سبورة. الكتاب ينفتح داخل إطار `book.html`.

## الاشتراكات والأجهزة
كل حساب (عدا المدير) له تاريخ انتهاء بـ `users.json`؛ الحسابات القديمة بدون تاريخ تنتهي `2026-12-01`. الجلسات والحظر عبر خادم الأجهزة المشترك (شوف `zraij/reading1/NEW_BOOK.md`).
